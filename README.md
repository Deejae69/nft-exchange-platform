# NFT Exchange & Digital Asset Platform

A polished MVP for an NFT marketplace and digital asset exchange platform built with React + Vite.

## Overview

This project includes:
- Marketplace landing page
- Trending NFT collections
- Liquid marketplace cards with bids and floor prices
- Portfolio and wallet dashboard
- Digital asset analytics panel
- Creator and collection management sections
- Responsive dark theme UI for DeFi/NFT experiences

## Features

- Hero section with CTA and wallet connection flow
- Search/filter-friendly marketplace layout
- NFT cards with price, trending score, and rarity
- Portfolio summaries and activity feed
- Analytics cards for volume, holders, floor price, and sales
- Responsive design for desktop and mobile

## Getting started

```bash
npm install
npm run dev
```

Then open your browser at the local Vite URL shown in the terminal.

## Production build

```bash
npm run build
```
